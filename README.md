# Job Listings Web Scraper (Python)

A Python web scraper that collects job titles, companies, and locations from a sample job board and saves the results to CSV.  
The scraper uses Requests to fetch the page and BeautifulSoup to parse the HTML.

Sample job board used for scraping:  
https://realpython.github.io/fake-jobs/

## 🚀 Features
- Scrapes job titles, companies, and locations
- Parses HTML using BeautifulSoup
- Saves results to a CSV file
- Clean and beginner‑friendly code structure

## 🛠 Technologies Used
- Python 3
- Requests
- BeautifulSoup4
- CSV module

### 2. Run the script
