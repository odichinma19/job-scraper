# Job Listings Web Scraper (Python)

A Python web scraper that collects job titles, companies, and locations from a sample job board and saves the results to CSV.

## 🚀 Features
- Scrapes job listings
- Extracts title, company, and location
- Saves results to CSV
- Uses BeautifulSoup for HTML parsing

## 🛠 Technologies Used
- Python 3
- Requests
- BeautifulSoup4

## ▶️ Running the Scraper
pip install -r requirements.txt
python scraper.py
